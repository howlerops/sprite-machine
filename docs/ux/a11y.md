# Accessibility checklist

Maintained list of accessibility checks for the Sprite Machine clients. Desktop is
`crates/client-gpui`. Mobile is the native app decided and built under M3-015/M3-016; the
interim mobile web page (`web/`) follows its own Playwright tests. Source of the list: plan
`docs/PLAN-v2-ade.md` section 3 item 11, the mobile hard gates near line 349, and the M3 exit
review (`docs/ledger/reports/M3-review.md`, "Accessibility audit").

Rule for every new screen: add or update its row here in the same change. A check that has
no test and no manual step is not a check.

## Checklist

"Status" is as of M3-019. Test names are in `crates/client-gpui/tests/`.

## Manual checks

For a human on a Mac (desktop) and, later, on the phones (M3-016). Run these with the
default text size first, then once more at Larger. Record the outcome in the results table.

### VoiceOver on macOS

Turn VoiceOver on with Cmd+F5. Use VO (Ctrl+Option) with the arrow keys to move, VO+Space to
activate. Quit with Cmd+F5.

1. Inbox
   1. Sign in and open the Inbox. VoiceOver should name the window and the page ("Page content").
   2. Move through the sidebar: each item reads "<Section>, current page" for the open one and "Go to <Section>" for the others.
   3. Move into the list. Each row reads its title, status and agent, and whether it is waiting on you. Failed and cancelled rows say so.
   4. Tab between the filters; each reads its name and current value.
   5. Switch the network off. The banner "You are offline..." is announced without moving focus.
2. Approval card
   1. Open a thread that is waiting for approval (a fixture agent asking to run a command).
   2. The waiting banner is announced. Move to the card: it reads what the agent wants to do, the command or file, and the risk.
   3. The Allow and Deny buttons read as buttons with labels that say what they do. Activate Deny with VO+Space and check the result is announced.
   4. Check the approval presets, if shown, are readable and in a sensible order.
3. Composer
   1. Press Cmd+N. Focus lands in the prompt, and VoiceOver reads its label.
   2. Type a prompt. Move to the agent, machine and attachment controls; each has a label and a value.
   3. Attach a file: the attachment chip reads its name and has a remove button.
   4. Send with Cmd+Enter. A failure or success is announced.
4. Settings
   1. Theme, Text size and Hub address controls read their label and, for the choice buttons, "selected" on the current one.
   2. Change Text size to Larger and back; the layout stays usable.
