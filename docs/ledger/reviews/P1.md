## Decisions taken during P1 (all logged in LOG.md)

1. **Hub-owned pending tasks; `session_config` tunnel command** (SPEC-002b, client-api §5.5a).
2. **Approval command outcome union** = selected | submitted | declined | cancelled (SPEC-002a).
3. **Machine credential check lives in the Machine DO.** The hash is stored in D1 and in the
   DO, the admin API provisions both, and revoke always tells the DO.
4. **Attachments**: images become ACP image blocks after magic-byte sniffing. Other files go
   to `.sm/attachments/`, referenced as `@path`.
5. **fs confinement via cap-std.** Absolute symlinks inside the root are re-based. A dangling
   symlink inside the root is now followed.
6. **Leader verifies merges after touching sources.** Concurrent worktree builds share one
   target dir and can clobber each other's artifacts. A private leader target was tried and
   then dropped for disk reasons.
