## Decisions taken during P0 (all logged in LOG.md)

1. **"No tokio" → "no tokio runtime"** in the hub (plan §4.2): workers-rs 0.8.7 always links feature-less tokio for its I/O traits. Enforced by `scripts/check-no-tokio-runtime.sh` in CI.
2. **ACP schema pinned to 1.12.0** (not 1.13.0) so `protocol` and the official SDK share one set of types.
3. **The hub emits `UserMessage`** when a task starts (SPEC-003); the tracer's runner-emitted one is a marked stub deviation, fixed by M2-008 / M1A-006b.
4. **Terminal closing snapshot repeats the full output** (turn-event.md §4.4 clarified).
5. **Hub wasm uses a `wasm-release` profile** (opt-level z, LTO, strip off): 507 → 412 KB gzip. Still ~3x the spike → MVP-000c.

## Incidents

- **Disk full (session allowance ≈ 40 GB)**: the shared target dir grew to ~22 GB (incremental caches, stale profiles). Two workers stopped mid-attempt; resumed on the same attempt. Fix: `CARGO_INCREMENTAL=0` in the ledger env, workers stop below 2 GB free, clean rebuild at each phase review (now 8.6 GB).
- **Container restart (OOM)** from two GPUI-sized builds at once: builds are now serialized.
- **macOS CI red** after M1A-003 (a `/proc`-only test): fixed with a portable `kill -0` check (mutation-checked).
- **Stale `cli` binary** from a shared target across worktrees pointed at a deleted checkout: the tracer now locates the hub at runtime.
- Two workers made a stray `create_session` call; both were denied, nothing was created. Briefs forbid it.
