## Store API for the tunnel client (M2B-004) and bridge (M1A-006b)
- Open: `Store::open(&state_dir)` / `Store::open_with_clock(&state_dir, Arc<dyn Clock>)`; `Store` is `Send + Sync` (internal mutex), share via `Arc`.
- Up outbox: `enqueue_outbound(event_id, &Value) -> seq` (idempotent per event_id), `ack_outbound(upto)`, `outbox_state() -> OutboxState{acked_upto, next_seq, unacked}`, `unacked_outbound()`, `restart_outbound_stream()` (on `welcome{resumed:false}`).
- Tunnel state: `set_resume_token(Option<&str>)`, `resume_token()`, `last_down_seq()`, `commit_down_frame(seq, Option<idempotency_key>) -> Disposition` (one tx; ack only after it returns), `observe_idempotency_key`, `restart_down_stream()`.
- Threads/tasks/sessions: `upsert_thread/thread/threads`, `upsert_task/task/tasks_for_thread`, `upsert_session/set_session_state/session_for_thread/sessions`, `detach_all_sessions()` (call at startup).
- Interrupts: `save_interrupt(&PendingInterrupt{..., expires_at_ms})` when emitting an Interrupt, `resolve_interrupt(id)` when answered, `take_expired_interrupts()`; at startup and on a timer call `acp::reattach::expire_overdue_interrupts(&store, |i| mapper)` and enqueue the returned `ExpiredRun.events`.
- Per prompt: `Reattacher::new(Arc<Store>)` (one per AcpClient connection), `prompt(&client, thread_id, harness, cwd, content)`; call `connection_lost()` when the agent process dies.
