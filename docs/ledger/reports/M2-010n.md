# M2-010n: failed and cancelled runs reach the thread list

## Summary
The Thread DO now records the last terminal outcome of a run. `RunError{reason:error}` sets the meta key `last_failure` to `failed`, `RunError{reason:cancelled}` to `cancelled`, and any `RunFinished{success}` clears it. The next `UserMessage` clears it as well. `index_row` reports `failed` / `cancelled` when no task is running or pending and no `done` applies, so `running` and `waiting` (needs_you, with an open interrupt) still win. The `status` column is not free text but its CHECK (0002) already allows failed and cancelled, so there is no migration, and old rows and reconcile are unaffected: a thread with no `last_failure` meta behaves exactly as before.
