## Decisions to review

- **First interactive** = shell rendered with the composer focused. It does not wait for feed data; a feed-mode shell starts empty and fills in. If `gates.yaml` means "first rows visible", the marker needs to move to the first applied batch.
- **Frame hook.** Frames are logged from renders of `AppShell`, `TranscriptPane` and `Composer`. A frame that repaints only other views would not be logged. Currently every visible part of the shell belongs to one of these views.
- **Float decoding.** Without `float_roundtrip`, serde_json decoded the fixture's `cost` values one ulp away from the source, so the streamed rows differed from the in-memory rows. The feature fixes this and adds no dependencies.
- **Single-threaded state.** `BenchLog` and the composer use `Rc`/`RefCell` because they live on the UI thread only.
