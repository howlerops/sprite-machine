## Decisions and notes

- **Approval clock.** The fixture's expiry (2026-10-27T22:10Z) is in the past for a wall clock. The card counts down from the 10-minute TTL from window open (`CardClock`, repaints once a second).
- **Approval fixture in process.** agui-fixture serves one scenario per process, and the fixture crate is out of scope, so a second server runs in the spike. It adds the tokio and reqwest code to the binary.
- **Terminal output** streams its 14 chunks at 200 ms intervals and then stops (about 3 s). It does not run for the 50 s bench.
- **Frame log.** Frames are logged from the transcript and composer renders. Terminal and card repaints appear in the log only when the transcript also re-renders, which the 200 ev/s stream does constantly.
- **Test stderr.** Dropping the approval fixture prints `fixture feed ... Connection reset without closing handshake` from the feed thread. Harmless.
