## Deviations
- **Route registration is in `worker.rs`, not `router.rs`.** The brief allowed one registration line in `router.rs`. The axum router is built in `worker.rs` (wasm32 only), and `router.rs` is platform-neutral. So the single line `.merge(crate::workspace_do::dev::routes())` went into `worker.rs`. The handler stays in `workspace_do/dev.rs`. The leader should confirm this is acceptable.
- **Trait style.** `async fn` in the trait is written as `fn ... -> impl Future`, which avoids the `async_fn_in_trait` lint without an `#[allow]`.
- **Commit trailer.** The brief names `Co-Authored-By: Claude Opus 5.5`, but the attribution reminder for this session names `Claude Haiku 5.5`, which is the model that did this work. The commit uses the Haiku line from the reminder. The leader can amend the trailer if it wants Opus.
- **DEV_FIXTURES off.** The 404 with the var unset is not exercised by a live run; only the path with `DEV_FIXTURES=1` is.
