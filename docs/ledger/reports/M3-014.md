# M3-014: client: command palette + shortcuts

## Summary

Command palette overlay (Cmd/Ctrl+K) with fuzzy-filtered, ranked commands: new task, go to every
page, next/previous thread, and one "open thread" command per inbox thread (by title). Escape
closes, Enter runs the selected command, Up/Down select (wrapping), a click runs a row. Cmd/Ctrl+N
shows the composer and focuses its prompt. Cmd/Ctrl+Enter (already bound in `compose`) submits the
composer when it has focus. Alt+Down / Alt+Up open the next / previous thread in inbox order via
`AppShell::open_thread` (stops at the ends). All shortcuts live in one table, `palette::SHORTCUTS`,
and the palette shows each command's shortcut label (`⌘K` on macOS, `Ctrl+K` elsewhere).

Decisions:
- Thread navigation is Alt+Down/Up, not Cmd+]/[: the text input binds Cmd/Ctrl+] and [ to
  indent/outdent. Documented in the `palette` module rustdoc.
- "secondary" modifier: `KeyBinding::new` at this pin uses `Keystroke::parse`, which rejects
  `secondary-` (only `parse_with_os` resolves it). The table spells out mac and other strokes;
  tests use `secondary-` through `window.press`, which does resolve it.
- Shell shortcuts are also bound under `Shell > Input` so they work while a text field is focused.
- Fixed a latent focus bug exposed by focusing the prompt: switching page with Ctrl+Tab removed the
  focused prompt from the tree, so the next shortcut (Ctrl+Shift+Tab) reached nothing. The section
  shortcuts and palette `Go to` now refocus the shell root first.
