# M3-004: desktop new-task composer

## Summary
- `compose/new.rs`: plain-Rust `NewTaskModel` (machines, agent, workspace path + spawn, mode, title, prompt, file-backed draft, validation, idempotent `CreateThread` request).
- `compose/mod.rs`: thin `ComposeView` (buttons, `InputState`, `Textarea`), Cmd/Ctrl+Enter bound as `SendTask` in context `Compose > Input`; background work runs on its own thread and is polled with `pump` (GPUI test scheduler forbids foreign-thread wakeups).
- Mounted on the shell's New task page (small `view.rs` diff); draft lives next to `preferences.json`.
- Limits (hub has no listing APIs yet): fixed agent list (claude, codex, opencode, pi, gemini, goose) narrowed to the machine's advertised `harnesses`; fixed permission-mode list; workspace is a typed folder path on the chosen machine. New-from-repo and model choice are not offered.
