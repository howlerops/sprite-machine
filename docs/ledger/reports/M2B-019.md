# M2B-019: E2E: start on the computer, continue from the phone, survive a dropped tunnel

## Summary
- `cargo run -p cli -- e2e rc`: hub under `wrangler dev`; the computer is the production `sm --rc` TUI `Session` (real bridge, in-process acp-mock, the runner's real tunnel client) driven with keys; the phone is a headless client-core (list, `Subscription`, `Outbox`, image upload).
- The tunnel runs through a TCP proxy that is cut mid-turn (an approval open) and restored. The phone answers the approval and the computer types while it is down; after the restore the transcript is gap-free (seq 1..51), each message and reply once, both approvals resolved once, equal to a fresh replay from the hub.
- `web/tests/rc.spec.js` does the same steps from the mobile web page in Chromium; the computer is `cli e2e rc-runner` (stdin commands `type`, `cut`, `restore`, `prompts`, `seen`).
- `docs/remote-control-parity.md`: feature-by-feature table vs Claude Code Remote Control, with status, evidence and the gaps found.
- One finding: a line typed in the TUI while a task runs is refused by the bridge and never shown (see Discovered work).

## Notes
- Worktrees share one cargo target dir, and cargo decides freshness by file mtimes, so another tree's `cli` build can stand in for this one (`debug/cli` was another tree's binary once). The spec therefore touches the sources (as the dev setup asks before builds), builds with `--message-format=json`, copies the binary to a temp dir and probes it for `rc-runner`, retrying up to 3 times. A plain `cargo run` in CI does not need this.
- `Presence` and `StateSnapshot` events take `seq` numbers in the thread log; the checks count messages by type, not by `seq`.
- The tunnel timing in the check is short (50 ms to 400 ms backoff) so the restore is quick.
- `e2e rc-runner` reads `SM_RC_BASE`, `SM_RC_MACHINE`, `SM_RC_CREDENTIAL` (the Playwright machine's, from `pairMachine`) from the environment; nothing is printed.
- This check covers most of M2B-010b's acceptance (TUI registers, phone prompt shows in the TUI log, tunnel drop and restore) except `/rc` typed by hand (registration is `autoConnect`) and a rendered screen.
