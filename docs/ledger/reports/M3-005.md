# M3-005 report: composer slash commands, mode/model, queued chips, Stop

## Summary
- `compose/commands.rs`: window-free decisions. `SessionOptions::from_state` reads the thread's `session` state (available_commands, modes, current_mode_id, the `model` config select, groups flattened); `slash_query` / `filter_commands` (prefix, then contains, then description); `accept_command` (a command with an input hint is inserted as `/name `, one without is sent); `allowed_modes` never offers a mode looser than the runner cap (`cap_from_features`); `ThreadRequest` (SetMode, SetConfig, RemovePending: method, path, body) and `ComposerEvent`.
- `compose/queue.rs`: queued chips from the `thread` state's `pending_tasks`, the running task, `stop_intent` (`Intent::Cancel`), `remove_request` (only for queued tasks).
- `compose/thread.rs`: `ThreadComposer` view. `/` opens a command list (click, Up/Down, Enter in context `SlashOpen > Input`), mode and model pickers, queued chips with Remove, Stop while a task runs. It only emits `ComposerEvent`s; the owner sends them and calls `set_thread` again when the hub's StateDelta arrives.
- `locales/en/compose.ftl`: `compose-thread-*` strings. `tests/compose_commands.rs`: 12 tests.
