# M2B-009a: sm rc session URL and spacebar QR

## Summary
- `sm rc` prints `session: <hub>/t/<thread id>` each time a session starts (start, dispatch, `-c`, reopen), via a `server::run_announcing` sink seam.
- On a terminal, stdin is read in raw mode (ICANON and ECHO off, ISIG kept so Ctrl-C works as before); a space shows or hides the QR of the latest session URL. The guard restores the terminal on drop.
- With no terminal, raw mode is never enabled and no key reader starts.
- Unsafe-free dependency choice: `libc` (already in the tree) instead of `crossterm`, which is not in the lock.

## Files changed
- `crates/runner/src/qr/keys.rs` (new): `Latest` (shared latest URL), `pump` (key handler over any `Read`/`Write`), `RawMode` guard (termios, unix; no-op stub otherwise).
- `crates/runner/src/qr/mod.rs`: `pub mod keys`, re-export of `Latest`.
- `crates/runner/src/server/mod.rs`: `run_announcing(options, sink, shutdown)`; `run` and `run_with_file_policy` pass no sink. `Options` is unchanged, so `cli` and `trust.rs` still build.
- `crates/runner/src/server/router.rs`: `Context` gets `hub` and `session_started`; `spawn_session` calls `announce`, which builds `qr::session_url` from the hub (ws form mapped to http, as the sign-in link does).
- `crates/runner/src/server/signin.rs`: `http_base` is `pub(super)`.
- `crates/runner/src/main.rs`: `run_rc` enables raw mode when stdin is a TTY, starts the key reader thread, prints the session line, and calls `run_announcing`.
- `crates/runner/Cargo.toml`: `[target.'cfg(unix)'.dependencies] libc = "0.2"`.
- `Cargo.lock`: one line, `libc` added to runner's dependency list (version already locked).
- `crates/runner/tests/qr.rs`: 4 tests added (key handler and raw-mode no-op).
- `crates/runner/tests/server_mode.rs`: 1 test added.
- `docs/ledger/reports/M2B-009a.md` (this report).
