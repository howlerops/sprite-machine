# M3-006a report: a user's own image parts render inline

## Summary
- `client-core` `UserView` gains `parts: Vec<ContentPart>` (the message's parts as sent). `text` is unchanged (joined text, files as `[file: name]`), so the runner TUI and other callers are untouched.
- `task/transcript.rs`: `Item::User` rows call `media::push_image_rows(&user.parts, 1, out)` after the text rows, so a user's http(s) image file part gets the same `RowKind::Image` thumbnail row, click-to-open panel and "could not be loaded" fallback as tool images.
- Row cache: `UserView` equality now covers the parts, so an item is rebuilt only when it changes; image rows are part of that item's segment.
- `tests/transcript.rs::all_example_variants_are_laid_out_in_the_window` skips Image rows when matching text labels: the `UserMessage.json` example carries a `screen.png` part, which is now a thumbnail row rather than a text row.

## Criteria
- UserView keeps content parts, text unchanged: MET. `a_user_view_keeps_its_content_parts_and_the_joined_text` (parts equal the event's; text is `see\n[file: a.png]`). Runner TUI tests green.
- User image part shows a thumbnail row with the tool-image behaviour: MET. `a_users_image_part_becomes_an_image_row_after_the_text` (Image row, `THUMB_ROW_HEIGHT`, after the text); `a_users_image_renders_inline_and_falls_back_when_it_cannot_load` (real pane: ready thumbnail labelled "Image mine.png", click opens the panel; a failing URL shows "Image mine.png could not be loaded.").
- Row cache equals the full rebuild and rebuilds only the changed item: MET. `a_users_image_rows_are_rebuilt_per_item_and_equal_the_full_rebuild` (50-item thread: the new user item rebuilds 1 item / 3 rows, `cache.rows() == full rebuild`, one Image row; a later delta rebuilds 1 item and still equals the full rebuild).
- Tests fail without the change: the new core test does not compile without `UserView::parts`; the row and pane tests find no Image row without the `push_image_rows` call (the existing example-layout test would also have needed the skip above only because of the change).
