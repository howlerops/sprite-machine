# M3-017: cli e2e app: drive a task from client-core against hub + fixture agent

## Summary
- Adds `cli e2e app`: the tracer stack (wrangler dev hub, runner with acp-mock, bridge and tunnel) with a headless client that uses client-core's public API (`Subscription`, `Outbox`, `Cache`) to answer the approval and wait for `RunFinished{success}`.
- The thread is created with a raw `POST /v1/threads`, because client-core has no create-thread intent.
- Tracer helpers are made `pub(super)` (visibility only). `tracer.rs` logic is unchanged.
