# M2-003f report: bootstrap owner GitHub login

## Summary
- `BOOTSTRAP_OWNER_GITHUB_LOGIN` (read in `github_routes.rs` into `GithubConfig.bootstrap_login`, lowercase, valid login only) names the bootstrap owner's GitHub login.
- The first GitHub sign-in of that login links the bootstrap owner, whatever the account's age, only while that owner has no `github_id` (and no other login). Only the user named by the hub's `auth.bootstrap` audit row is reachable; it is audited as `auth.github.link` with `by: bootstrap_owner_login`.
- No migration and no `bootstrap()` change: the bootstrap route is in `routes.rs`, which is not in the allowed files, so the login is applied at sign-in time, not stored at bootstrap.
- Native tests pass. The live test is written but NOT verified: the live suite could not get wrangler ready in this environment (see Verify).

- `crates/hub/src/auth/github.rs`: `GithubConfig.bootstrap_login`; `finish_callback` tries the bootstrap link before the 7-day login link; `redeem` audits the bootstrap link.
- `crates/hub/src/auth/github_store.rs`: `link_bootstrap_owner`.
- `crates/hub/src/auth/github_routes.rs`: reads `BOOTSTRAP_OWNER_GITHUB_LOGIN`.

- `docs/specs/client-api.md` (§5.9, one line), `docs/ops/hub.md` (one paragraph under Secrets).

## Criteria
1. With `BOOTSTRAP_OWNER_GITHUB_LOGIN` set, the first GitHub sign-in of that login becomes the owner: MET natively. `auth::github_tests::the_bootstrap_owner_is_linked_by_the_configured_login_whatever_its_age_and_only_once` (PASS) and live `the_bootstrap_owner_signs_in_with_the_configured_github_login_and_no_other_login_can` (written, NOT RUN).
2. Another login cannot use it: MET natively. `auth::github_tests::no_other_login_can_use_the_bootstrap_owner_link` and `...the_bootstrap_link_needs_the_bootstrap_audit_row_and_an_owner_without_a_github_id` (both PASS). Live test covers a mallory login refused (NOT RUN).

## Choice (login-link rule)
- Narrow: only the user named by the `auth.bootstrap` audit row of the org, only while `github_id IS NULL` and the login is unset or equal, once (linking sets `github_id`; a later sign-in finds the owner by id). Not limited by age, because the operator set the login. The 7-day rule (M2-003e) is unchanged for all other users.
