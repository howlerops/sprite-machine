# CI-002 report: per-worktree hub wasm target dir

## Summary

- The hub's wasm32 build (hub-test.sh, the tracer and the attachments check, and the wrangler `[build]` rerun) now goes to `$CARGO_TARGET_DIR/wasm-<16 hex of sha256(checkout root)>`, so two worktrees never share hub wasm artifacts. Native builds keep the shared dir.
- One wasm profile per worktree: `wasm-release` everywhere (CI-002b adopted; hub-test.sh used `--release`).
- The build log must name `(<this worktree>/crates/hub)`; `CARGO_TERM_VERBOSE=true` makes cargo print `Fresh hub v0.1.0 (<path>)` on cached builds too.
- Found while verifying: wrangler dev's default inspector port (9229) is held by other workers' workerd on this machine, so wrangler failed with `Address already in use`. Both wrangler launches now pass `--inspector-port 0`.
- All three verify commands and the new unit test pass. Per-worktree wasm dir: 538 MB.

## Files changed

- `scripts/hub-test.sh`: `REPO` via `pwd -P`; `WASM_TARGET_DIR` keyed by the root under the shared target dir; `worker-build --profile wasm-release` with `CARGO_TARGET_DIR=$WASM_TARGET_DIR CARGO_TERM_VERBOSE=true`; the run fails unless the build log contains `($HUB_DIR)`; wrangler gets `HUB_WASM_TARGET_DIR` and `--inspector-port 0`. `cargo test -p hub --features live` is unchanged (shared dir).
- `crates/hub/wrangler.toml` `[build] command` only: `env ${HUB_WASM_TARGET_DIR:+CARGO_TARGET_DIR=$HUB_WASM_TARGET_DIR} worker-build --profile wasm-release && cargo run -q -p cli -- wasm strip-names build/index_bg.wasm`. The `cargo run` for the strip step keeps the shared dir; the empty-variable case is handled by the `:+` (cargo rejects an empty `CARGO_TARGET_DIR`).
- `crates/cli/src/e2e/tracer.rs` (shared by the tracer and the attachments check): `wasm_target_dir(hub_dir)` (sha2 of the canonical root, first 8 bytes as hex, under `CARGO_TARGET_DIR` or `<root>/target`); `build_hub` sets `CARGO_TARGET_DIR` and `CARGO_TERM_VERBOSE=true` and fails unless the log names `(<hub_dir>)`; `Wrangler::start` passes `HUB_WASM_TARGET_DIR` and `--inspector-port 0`; unit test `wasm_target_dir_is_keyed_by_the_checkout_root`.
- `docs/ledger/reports/CI-002.md`: this report.
