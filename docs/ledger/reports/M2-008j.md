# M2-008j: scheduled purge of expired subscribe tickets

## Summary
- `auth::ticket::purge(db, now_ms)` deletes subscribe tickets past `expires_at_ms` and used tickets whose `used_at_ms` is older than `USED_GRACE_MS` (60 s).
- The hourly cron (`worker.rs` `scheduled`) calls it next to the devices and GitHub purges.
- Mint's own sweep is kept, so existing behaviour and `minting_sweeps_old_tickets` are unchanged.
- Native test with an injected clock: `auth::ticket::tests::the_hourly_purge_drops_expired_tickets_and_spent_ones_past_the_grace`.

## Files changed
- `crates/hub/src/auth/ticket.rs`: `USED_GRACE_MS`, `purge`, native test module.
- `crates/hub/src/worker.rs`: `purge_subscribe_tickets` (wasm-only), called from the cron.
- `docs/ledger/reports/M2-008j.md`: this report.
