# M2B-009: runner: session URL, QR code, `sm mobile`, auto-connect setting

## Summary
- Added the testable parts: the session URL builder (`https://<hub>/t/<id>`), the terminal QR renderer, a spacebar QR toggle, and the `settings.json` loader with `autoConnect` (default false).
- `sm mobile [--hub <url>]` is wired: it prints the QR and URL of the hub's mobile web page.
- Not wired: the session URL and spacebar toggle are not called from `sm rc` or any interactive loop, and nothing reads `autoConnect` yet. Those call sites are outside this item's paths (see Discovered work).

## Files changed
- `crates/runner/src/qr/mod.rs` (new): `session_url`, `mobile_url`, `block`, `render` (re-export of `login::flow::qr_text`), `QrToggle`.
- `crates/runner/src/settings.rs` (new): `Settings { auto_connect }`, `parse`, `load`, `FILE = "settings.json"`.
- `crates/runner/src/lib.rs`: two module declarations (`qr`, `settings`).
- `crates/runner/src/main.rs`: `mobile` subcommand (`run_mobile`), its usage line, and the `use runner::qr` import.
- `crates/runner/tests/qr.rs` (new): 7 tests.
- `docs/ledger/reports/M2B-009.md` (new): this report.

`Cargo.toml` and `Cargo.lock` are unchanged. `qrcode` was already a dependency.

## Acceptance criteria
1. **Prints the session URL `https://<hub>/t/<id>`**: partly met. The builder is `qr::session_url`, which normalizes the hub and validates the id. Test: `the_session_url_is_the_hub_deep_link`. The call that prints it from `sm rc` is not wired.
2. **Spacebar toggles a terminal QR**: partly met. `QrToggle::on_key(' ')` toggles and other keys do nothing; `view` prints the block only when shown. Test: `space_toggles_the_qr_and_other_keys_do_nothing`. No live key loop calls it.
3. **`sm mobile` prints a QR for the mobile web page / app install**: met. Wired in `main.rs`. Tests: `the_mobile_url_is_the_hub_web_page`, `the_qr_is_a_multi_line_text_block_that_depends_on_the_data`, `the_block_has_the_qr_and_the_link`. The smoke run above is also evidence.
4. **`autoConnect=true` registers every interactive session**: partly met. The setting loads with default false. Tests: `auto_connect_is_off_by_default`, `auto_connect_true_is_read_from_the_state_dir`. Nothing reads `Settings::auto_connect` to register sessions.

Blocked on: nothing. The unwired parts need code outside this item's paths.
