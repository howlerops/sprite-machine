## Deviations and notes

- **tokio dev-dependency.** The integration test must run `agui_fixture::start`, which calls `tokio::spawn` and needs a runtime. The brief allowed only an HTTP client; tokio was added as a dev dependency.
- **Fixture subscription.** The fixture starts its emitter only when a WebSocket subscriber connects (`server.rs`, `subscribe`). The integration test sends a raw HTTP upgrade over `std::net::TcpStream` (checking for `101`) instead of adding a WebSocket crate. It then retries the POST while the fixture answers 404 `unknown_interrupt`.
- **Route prefix.** The fixture serves `/threads/{id}/...` without the `/v1` prefix from client-api.md §5.4. `HttpAnswerSink::new(base_url)` takes the origin, so the prefix can be added by passing `http://host/v1`.
- **Test id on a button.** `Button` does not implement `TestSupportExt` (its `PrepaintState` is not `Option<Hitbox>`), so each option is wrapped in an observed `div` whose id is `approval-option-<id>`. The button inside has id `approval-option-<id>-button`. Clicking the wrapper's centre clicks the button.
- **Tool-call summary.** The card shows the interrupt's message (or title) and the tool-call id. The pending diff or command (PLAN §3) is not shown: the interrupt carries only the id, and the diff lives in the log (`Activity{Diff}`). Not built here.
- **Time left.** `ApprovalCard` takes `now_ms` at construction and in `set_now`. Nothing ticks it: the app must call `set_now` on a timer. The headless tests fix the clock 5 minutes before expiry.
- **Not wired into the app.** `main.rs` still opens the transcript shell, and the approval modules are not reachable from it. The card runs only in tests.

## GPUI API notes

- `Button::new(id).label(..).disabled(bool)` with `ButtonVariants::success()` / `danger()` for tone; `.on_click(impl Fn(&ClickEvent, &mut Window, &mut App))` takes a `cx.listener(...)` directly.
- `cx.listener` returns a `'static` closure, so it can be built in a loop and passed to a helper. A `.map(|o| helper(o, cx))` closure over `cx` fails with "captured variable cannot escape `FnMut` closure body"; build the buttons in a `for` loop, then call `cx.theme()`.
- Rust 2024 `impl IntoElement` captures the borrowed `&OptionView` and `&mut Context`; the helper takes owned `String`s and an `impl Fn` instead.
- `window.click` / `window.find` take `impl Into<ElementId>`; a `&str` borrowed from a temporary `String` fails with E0716 (the test ids are `'static`). Pass the `String` itself.
- `TestAppContext::run_until_parked()` drives the background `answer` call and the foreground `update` that applies its reply; no timers are needed.
- `agui_fixture::Event::Interrupt` holds a `Box<Interrupt>`; unbox it with `*`.
