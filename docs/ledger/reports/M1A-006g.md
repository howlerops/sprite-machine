## Answer to the leader's question

`sm rc` never sends a local prompt. The only `send_local` call is in the sidecar bridge test. The
runner server router (`server/router.rs`) forwards only commands from `TunnelCommands`, which are all
`Hub` origin, and `-c` / `--continue` only reopens the stored thread (`router.rs` ~line 411). So
the runner server path needs `origin: incoming.origin` and never produces `Local`.
