# M2B-004d: runner: OS sleep hook calls SleepHint::asleep; TunnelSink tracks opened threads

## Summary

Adds `sleep::SleepWatcher` with a Linux watcher (logind `PrepareForSleep(true)` over the system D-Bus, `zbus` with tokio, no default features) and a macOS placeholder that is a compiled-in TODO. `sleep::spawn` forwards each pre-sleep notification to `SleepHint::asleep`. If no watcher can start, it logs a warning and the runner keeps running. `TunnelSink` now tracks runner-started threads: `thread_open` is queued at most once per thread, and events for a marked local thread that was never opened are refused. Events for hub-dispatched threads still go out.

## Acceptance criteria

1. **Met.** `SleepWatcher` trait with Linux (`LogindSleepWatcher`, `cfg(target_os = "linux")`) and macOS (`MacSleepWatcher`, `cfg(target_os = "macos")`, TODO stub). `forward` calls `SleepHint::asleep` per notification.
   - `each_pre_sleep_notification_sends_presence_asleep` (sleep_hook.rs): fake watcher, two notifications give two `presence{asleep, os_sleep}` frames on the fake hub. Dropping the watcher ends `forward` with its error, and the client keeps running.
   - `without_a_system_bus_the_linux_watcher_fails_and_does_not_panic` (sleep_hook.rs): a bogus bus address gives `Err`.
   - Caveat: `sleep::spawn` is not called from anywhere yet (see Discovered work). The macOS watcher is not implemented.
2. **Met.** `TunnelSink::thread_open` is queued once per thread id. A second call returns `Err`. Events for a thread marked with `mark_local_thread` and not opened are refused, and nothing is queued for that batch. Events for unmarked (hub-dispatched) threads are sent.
   - `thread_open_is_queued_at_most_once_per_thread` (tunnel_client.rs): second call is `Err`, one frame in the outbox, one `thread_open` on the wire.
   - `an_event_for_a_local_thread_before_its_thread_open_is_refused` (tunnel_client.rs): refused before the open, nothing queued, then accepted after it, and the event follows `thread_open` at seq 2.
   - `hub_dispatched_threads_send_events_without_thread_open` (tunnel_client.rs): unmarked thread's event is sent with seq 1, and the marked unopened thread's event is refused in the same test.

## Design notes and limits

- "Told runner-started" is `TunnelSink::mark_local_thread(thread_id)`. `thread_open` then opens it. A thread that is neither marked nor opened is treated as hub-dispatched. A caller that forgets to mark a local thread gets no refusal (same as before this item).
- A second `thread_open` returns `Err` rather than silently returning the first seq, so a caller bug is visible.
- The Linux watcher does not take a logind `delay` inhibitor, so logind may suspend before `asleep` is written. The hint is best effort (tunnel.md §3.7) and has a 1 s bound. The inhibitor is a follow-up.
- Nothing calls `sleep::spawn`, `mark_local_thread` or `thread_open` outside tests. `main.rs` and the session start path are outside this item's allowed files.

## Discovered work

```yaml
- title: "runner: start sleep::spawn(hint) at runner startup"
  why: "sleep::spawn and the Linux watcher exist, but nothing starts them. The runner's main/tunnel start path must call tunnel client sleep_hint() and sleep::spawn before TunnelClient::run. main.rs was outside M2B-004d."
- title: "runner: logind delay inhibitor around the sleep hint"
  why: "Without an inhibitor from Manager.Inhibit(sleep, delay), logind may suspend before presence{asleep} is written. Hold the inhibitor fd, send the hint, then drop it, so the hint is written before sleep."
- title: "runner: macOS sleep watcher (IOKit IORegisterForSystemPower or NSWorkspace willSleep)"
  why: "sleep/macos.rs is a compiled-in TODO that returns an error. It has not been compiled or run on macOS. Implement it on a macOS host and test it there."
- title: "runner: call TunnelSink::mark_local_thread and thread_open when a local session starts"
  why: "The TUI, /rc, desktop app and auto-connect paths must mark and open their thread before its first event. Until they do, the refusal in TunnelSink::send is not exercised outside tests."
```
