# M1A-006d: single down-commit owner

## Summary

The tunnel client is now the only owner of `Store::commit_down_frame`. The bridge's `on_incoming` reads `Store::seen_key` (plus an in-process set for repeats before the commit), applies, and calls `CommandSource::processed(seq, key)`; it never advances `last_down_seq`. `TunnelCommands` forwards the key from `processed`, so the FIFO seq-to-key mapping is gone and out-of-order reports are handled by key.

## Notes

- The store records a key only after the source commits it, so the bridge keeps an in-memory `applied` set for repeats in between (the tunnel client's `in_flight` covers the same case on its side). The set is unbounded for the process lifetime.
