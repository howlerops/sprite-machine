# M2B-007b: sm rc reopens closed sessions, acp-mock MCP capabilities, local close

## Summary

A prompt for a thread whose idle session was closed (hub cancel, idle timeout, or the new `sm rc close`) reopens it: a worktree session gets its worktree back with `git worktree add <path> sm/<name>` (the session's own branch, now created at spawn instead of a detached HEAD), then the bridge resumes the ACP session. acp-mock scripts set the `initialize` `mcp_capabilities` (`mcp_capabilities`: `{http, sse}`), and both M2B-007a relay patches are gone. `sm rc close <thread id>` asks the running `sm rc` over `<state dir>/rc.sock` (unix socket, mode 0600, one request per connection); it ends an idle session like an idle close and refuses a session with a task running.

## Files changed

- `crates/runner/src/server/worktree.rs`: worktrees are added on a new branch `sm/<name>` (`Worktree::branch`); `Worktree::restore` adds one back on its branch; `Worktree::save` / `load` keep the record `worktree.json` in the session's directory; `sweep` uses `repo_of` / `git_remove`.
- `crates/runner/src/server/router.rs`: `reopen` restores a missing worktree from the record (else "workspace is gone" as before); `start_session` saves the record; `local_close` answers `sm rc close`; the run loop takes the control socket's requests.
- `crates/runner/src/server/local.rs` (new): `Listener` (bind `<state>/rc.sock`, 0600, removed on drop; refuses to start if another server answers on it), `close_session` (client side of `sm rc close`).
- `crates/runner/src/server/mod.rs`: binds the listener for the life of `run`; `pub use close_session`; docs.
- `crates/runner/src/main.rs`: `sm rc close <thread id>` (`run_close`), usage line.
- `crates/runner/tests/server_mode.rs`: the agent child no longer relays `initialize`; the http/sse test sets `mcp_capabilities` in its script; `received_by(rig, n, ..)`; 3 new tests.
- `crates/acp-mock/src/{script,agent,lib}.rs`: script key `mcp_capabilities` (`Script::mcp_capabilities()`), advertised by `initialize`.
- `crates/acp-mock/tests/scripts.rs`: `initialize_advertises_the_scripts_mcp_capabilities`.
- `crates/sidecar/tests/session_config.rs`: `Rig::start_with` sets `mcp_capabilities` in the script; the relay is removed (acp-mock writes straight to the duplex).

## Acceptance criteria

1. Met. `a_prompt_after_an_idle_close_adds_the_worktree_back_on_its_branch_and_resumes_the_session`: a hub cancel of the idle thread removes the worktree; the next prompt re-adds it, on the same branch (`git rev-parse --abbrev-ref HEAD`), with no new branch (`git branch` list unchanged), and the second agent process gets `session/resume` or `session/load` and no `session/new`. The local close test (below) covers the same path after `sm rc close`. Without the change the prompt fails with "workspace ... is gone" and the test times out waiting for `RunFinished`.
2. Met. `initialize_advertises_the_scripts_mcp_capabilities` (acp-mock, including an invalid `mcp_capabilities` rejected at load). `http_and_sse_mcp_servers_are_passed_when_the_agent_advertises_them` and `the_mcp_provider_gets_the_agents_advertised_capabilities` (sidecar) now get their capabilities from the script. The relay patches are removed from both files.
3. Met. `a_local_close_ends_an_idle_session_and_the_next_prompt_reopens_it`: `server::close_session(state, "th_1")` (the function `sm rc close` calls) ends the session, removes the worktree, stops the agent process, leaves the socket at mode 0600, and the next prompt reopens the session; the socket is removed when the server stops. `a_local_close_of_a_running_session_or_an_unknown_thread_is_refused` covers the refusals (a session with a task running, an unknown thread).

Transport: a unix socket at `<state dir>/rc.sock`. Protocol: one line `close <thread id>` from the client, one line back, `ok` or `err <reason>`.

## Decisions and limits

- Worktrees are on a new branch `sm/<session name>` (was `--detach HEAD`). Each worktree session leaves its branch in the project repository after it ends (commits are kept, which is the point). Branches are never deleted by the runner.
- The socket is bound, then chmod'ed to 0600; a brief window exists where it has the umask mode. The state directory is owner-managed.
- A local close does not stop a session with a task running; the hub `cancel` is the way to interrupt one.
- `sm rc -c` still continues the last session in the project directory (not its worktree); unchanged.
- A kept (dirty) worktree is not removed by the runner and is used as is on the next prompt (unchanged from M2B-007a).
