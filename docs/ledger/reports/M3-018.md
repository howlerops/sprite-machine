# M3-018: unsigned macOS app from CI

## Summary

A new workflow, `.github/workflows/desktop.yml`, has one job (`macos-app`, `macos-latest`). It builds `client-gpui` in release and bundles `Sprite Machine.app` with `scripts/bundle-macos.sh`. It then zips the app with `ditto -c -k --keepParent` and uploads it with `actions/upload-artifact@v4` (14-day retention).

It runs on push to `v2` (paths: `crates/**`, `Cargo.*`, the script, the workflow) and on `workflow_dispatch`. `rust.yml` is untouched, so the existing test jobs are not slowed. There is no signing, notarization or secret.

The build targets the runner arch only (arm64). A universal build was skipped: it needs two builds plus lipo, roughly double the time. This is documented.

## Files

- .github/workflows/desktop.yml
- scripts/bundle-macos.sh
- crates/client-gpui/bundle/Info.plist.in
- docs/ops/desktop-builds.md
- docs/ledger/reports/M3-018.md

`Cargo.toml` is unchanged: the bin is `client-gpui` (default from `src/main.rs`), so no `[package.metadata]` was needed. No earlier bundling script or cargo-bundle use exists in the repo.

## Verify (Linux)

- `bash -n scripts/bundle-macos.sh`: ok.
- shellcheck: not installed, not run.
- The script was run against a fake binary. The layout came out as `Sprite Machine.app/Contents/{Info.plist,PkgInfo,MacOS/client-gpui,Resources/}`.
- Info.plist, parsed with `python3 -I` plistlib: CFBundleIdentifier `app.spritemachine.desktop`, CFBundleName `Sprite Machine`, CFBundleExecutable `client-gpui`, CFBundleShortVersionString `0.1.0+abc1234`, CFBundleVersion `0.1.0`, LSMinimumSystemVersion `13.0`, NSHighResolutionCapable true.
- `yaml.safe_load` on desktop.yml: parses, jobs = [macos-app].
- The macOS job itself was NOT run (no macOS runner here). The cargo build, `plutil -lint`, `ditto` and the upload are unverified until CI runs.

## Criteria

- Builds client-gpui in release and bundles an unsigned .app with bundle id and version in Info.plist: the workflow steps plus the plist output above.
- Uploaded as a workflow artifact: `actions/upload-artifact@v4`, name `sprite-machine-macos-unsigned`, `retention-days: 14`.
- Docs say how to open an unsigned app: docs/ops/desktop-builds.md (right-click Open, `xattr -dr com.apple.quarantine`).
- Signing is listed as not done (M6-006).
