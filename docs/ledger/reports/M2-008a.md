# M2-008a: hub Thread DO hardening

## Summary

- `ThreadCore::append` redacts `event` and `raw` (secret patterns to `[redacted:<kind>]`, `threads/redact.rs`) before the size check, stamping, persistence and broadcast; derived titles come from the redacted event.
- Catch-up is a lazy `CatchUp` iterator that reads the log in pages of 500 rows; `do/thread.rs` is unchanged (it iterates the same way).
- State history is compacted at each `RunStarted` to one snapshot per scope for everything before the oldest of the newest 50 runs. Catch-up never starts before that floor (`after` is clamped to it), so output is unchanged for every `after` at or after the floor.
- `DEV_FIXTURES` is passed as `--var DEV_FIXTURES:1` by `scripts/hub-test.sh` and the tracer; `crates/hub/.dev.vars` is deleted. Live `thread_do` (7/7) and the tracer are green.

## Acceptance criteria

1. **Met.** Redaction covers the listed kinds (`anthropic`, `openai` incl. `sk-proj-`, `github` for `ghp_`/`gho_`/`ghs_`/`ghu_`/`ghr_`/`github_pat_`, `aws_access_key`, `aws_secret` for `aws_secret_access_key=...`, `bearer`, `private_key` PEM blocks, and `fake_api_key` for the acp-mock key). Tests: `redact_text_redacts_each_secret_kind`, `redact_text_leaves_ordinary_words_and_short_hex_alone`, `stored_and_broadcast_envelopes_are_redacted_in_event_and_raw` (stored log and `take_appended` both checked, `event` and `raw`), `ordinary_text_is_stored_and_broadcast_unchanged`.
2. **Met.** Pages of at most 500 rows (`CATCH_UP_PAGE`). Test: `catch_up_from_zero_over_20k_events_reads_pages_of_500_and_matches_the_log` (40 reads, each ≤ 500 rows, output equal to hello + empty snapshot + the 20k appended envelopes + live). A read error ends the replay with an `error` message: `catch_up_read_error_ends_the_replay_with_an_error_message`.
3. **Met with one deliberate rule.** Compaction keeps, per scope, only the latest change at or before the floor (the snapshot) and drops older rows. The floor is the seq before the oldest of the newest 50 runs. Test: `state_history_compaction_keeps_catch_up_output_unchanged`, which compares the compacted core with an uncompacted reference for every `after` from the floor to the head (identical). For `after` below the floor, catch-up starts at the floor: the old per-`after` snapshot needs changes that are now gone, so the output differs there by design (the test asserts it equals the floor's output). This clamp is a spec decision for the leader (see Discovered work).
4. **Met.** `scripts/hub-test.sh` and the tracer pass `--var DEV_FIXTURES:1`; `crates/hub/.dev.vars` is deleted; `thread_do` 7/7 and the tracer pass without it.
