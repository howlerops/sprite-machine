# M3-010d: shell passes the workspace root and receives OpenFile

## Summary

`AppShell::open_thread(thread_id, workspace)` now gives the transcript pane the thread's workspace root: `set_workspace_root(Some(path))` when the workspace is non-empty, `None` otherwise. The shell subscribes to the pane's `TranscriptEvent::OpenFile { path, line }` and keeps the last request. `AppShell::last_open_file()` returns it as `(&Path, u32)`. Because the pane is replaced for each new thread, the subscription is replaced with it.

The diff summary string (`transcript-diff-summary`) now uses the argument names `path`, `added` and `removed`. The shell catalog test's argument set was extended to match.

Not done: the debug-level log of the open-file request. `client-gpui` has no logging facade, and adding one means editing `crates/client-gpui/Cargo.toml`, which is outside this item's paths. Recorded as discovered work `M3-010d-log`.

## Files

- `crates/client-gpui/src/shell/view.rs`: `_pane_events` and `last_open_file` fields, `subscribe_pane`, `last_open_file()`, and `open_thread` now sets the pane's workspace root (also when the thread is already open, since its workspace may have changed).
- `crates/client-gpui/src/task/tools.rs`: the summary row's args are `path`, `added`, `removed`.
- `crates/client-gpui/locales/en/shell.ftl`: `transcript-diff-summary = { $path }: +{ $added } -{ $removed }`.
- `crates/client-gpui/tests/shell.rs`: catalog test's argument set adds `path`, `added`, `removed`; fixture `hub_with_a_diff`; helper `wait_for_shown`; two window tests:
  - `a_diff_in_a_thread_with_a_workspace_asks_the_shell_to_open_its_file`
  - `a_diff_in_a_thread_without_a_workspace_offers_no_open_file`

`tests/transcript.rs` and `task/transcript.rs` are unchanged. The summary output text (`src/lib.rs: +2 -1`) is the same as before.

## Criteria with evidence

- **Pane gets the thread's workspace root:** `a_diff_in_a_thread_with_a_workspace_asks_the_shell_to_open_its_file` opens `th_a` with `/work/repo`, clicks View diff, and the Open file element appears. Fails when the root call is removed (mutation check above).
- **Shell receives OpenFile and exposes the last request:** the same test clicks Open file and asserts `last_open_file() == Some((/work/repo/src/lib.rs, 13))`. The line 13 is the value the transcript test `open_file_from_the_diff_is_re_emitted_with_the_workspace_root` gives for the same fixture. The test does not compile without `last_open_file`.
- **No workspace, no Open file:** `a_diff_in_a_thread_without_a_workspace_offers_no_open_file` opens `th_a` with `None`, clicks View diff, finds the diff pane and no Open file element, and `last_open_file()` is `None`.
- **Summary string uses `path`, `added`, `removed`:** the catalog test formats every id with the argument set; with the extended set it passes, and the row text in the transcript tests is unchanged. The catalog test would report `{ $path }` as unformatted if the set were not extended. I did not run that failure separately.
- **Debug log of the request:** not done (see Discovered work).

## Not covered

- No editor: the request is only stored and exposed.
- `last_open_file` is not cleared when another thread is opened. It is the last request, whatever thread made it.
- The window tests use the fake hub's replayed frames; the transcript is laid out at 1000x700.
