# M2-008i: log and ticket-strip regression tests

## Summary
- The access-log line now takes the path-and-query and cuts the query itself (`router::access_log`); `observe` in worker.rs passes the full path-and-query, so a test pins that no query (ticket or `after=`) reaches the log.
- The ticket rewrite moved out of `strip_ticket_from_uri` (threads/routes.rs, wasm-only) into the native pure function `router::path_and_query_without_ticket`; `strip_ticket_from_uri` is now a thin wrapper around it.
- Native tests cover mixed queries (after=, ticket=, repeated keys, ticket first/last/only, empty and percent-encoded values) for both `strip_ticket` and the forwarded path-and-query.
- Live test `the_ticket_is_stripped_wherever_it_sits_in_the_query` shows the forwarded query still parses and the DO answers `hello` for each ticket position.
- Known gap, pinned and reported: a percent-encoded key (`%74icket=`) is not stripped and is forwarded as-is (see Discovered work).

## Files changed
- crates/hub/src/router.rs: `path_and_query_without_ticket` (new), `access_log` takes path-and-query and logs the path only; tests `access_log_records_the_path_and_never_the_query`, `ticket_is_stripped_from_mixed_queries_before_forwarding`.
- crates/hub/src/worker.rs: `observe` passes `path_and_query` to `router::access_log`.
- crates/hub/src/threads/routes.rs: `strip_ticket_from_uri` calls `router::path_and_query_without_ticket`.
- crates/hub/src/auth/ticket.rs (tests only): `strip_ticket_keeps_every_other_pair_in_order`, `ticket_in_query_reads_the_first_literal_ticket_pair`.
- crates/hub/tests/subscribe_ticket.rs: live `the_ticket_is_stripped_wherever_it_sits_in_the_query`.
- docs/ledger/reports/M2-008i.md (new).
